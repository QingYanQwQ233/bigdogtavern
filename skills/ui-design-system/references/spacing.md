# 间距、圆角、动效尺度

三类尺度都是**硬约束**，由 `scripts/check_design_scales.js` 守卫。改尺度要同时改三处：`AGENTS.md`、守卫脚本头部注释、`CHANGELOG`。

## 间距刻度

```
2 4 6 8 10 12 14 16 20 24 28 32 40 48 56 64 72
```

另允许 `0` 和 `1px`（贴边 / 发丝线）。

**步进不是线性的**，这是刻意的：

| 区间 | 步进 | 理由 |
|---|---|---|
| ≤ 16 | 2px | 小间距需要细调，2px 差异肉眼可辨 |
| 16–40 | 4px | 中尺度上 2px 差异已经不可辨，收窄避免选择困难 |
| ≥ 40 | 8px | 大留白上步进必须粗，否则没有节奏感 |

**基数不是 8 而是 2。** 这是历史决定并且已经全量对齐过：超过 20% 的声明曾经偏离网格 1px（3/5/7/9/11/13/15），那次一次性还清了。

### 用法

- **组内间距必须小于组间间距** —— 这是分组的唯一可靠信号
- 卡片内边距常用 `12 / 16`，卡片之间常用 `8 / 12`
- 面板全局边距常用 `16 / 20`
- 竖向节奏优先用 `padding` 而不是 `margin`（避免塌陷）

## 圆角刻度

```
0 2 4 6 8 10 12 16 20 999
```

另允许 `%` / `inherit` / `var(--radius)`。

**阈值规则（重要）**：原来同时存在 `99px` 和 `999px` 两套"胶囊"写法。迁移规则是 **≥ 50px 一律归一为 `999px`**，**不能**按就近对齐（会把 `99px` 落成 `20px`，胶囊被压成小圆角）。

| 圆角 | 用途 |
|---|---|
| 2 / 4 | 徽标、小标签 |
| 6 / 8 | 按钮、输入框 |
| 10 / 12 | 卡片、面板 |
| 16 / 20 | 弹窗、大容器 |
| 999 | 胶囊（chip、圆形头像） |

## 动效刻度

```
0 100 150 200 250 300 400 800 1000 1400 60000
```

**单位统一用 ms。** 不允许 `0.2s` / `1.4s` 这类秒制写法（曾经混用，已归一）。

| 时长 | 用途 |
|---|---|
| 100 / 150 | 悬停、焦点、颜色变化 |
| 200 / 250 | 展开收起、淡入淡出 |
| 300 / 400 | 抽屉、弹窗、面板切换 |
| 800 / 1000+ | 环境动效（背景氛围） |
| 60000 | 常驻循环（如呼吸光效） |

### 动效原则

- **只动 transform 和 opacity** —— 动 `width` / `height` / `top` / `left` 会触发重排
- 动效必须有目的：引导注意、表达状态变化、维持连续性。纯粹"看起来活泼"的动效应删掉
- **必须尊重 `prefers-reduced-motion`**

- [ ] 动效时长是 ms 单位吗？
