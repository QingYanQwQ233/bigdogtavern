提示词预设

预设 = System Prompt + 历史后指令。角色卡可绑定预设（角色 system_prompt 为空时自动使用）。

编辑预设 / 全局默认

未选择任何预设时，编辑的是「全局默认」System Prompt（所有角色兜底）。

世界书

「设为全局」对所有对话生效；角色卡可绑定专属世界书，仅该角色对话时生效。

世界书

示例：触发词「酒馆」→ 内容「酒馆名叫“断牙之角”，老板是一只独眼的老狼。」

🧠 玩家设定

玩家设定会以【玩家设定】段注入 System Prompt，AI 据此称呼/对待你。

💭 记忆条目（自动注入上下文）

记忆注入在【玩家设定】之后，帮助 AI 记住长期设定与剧情进展。可编辑内容、单独启用/停用。
