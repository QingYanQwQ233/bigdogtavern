# 《毛茸异：星穹与深渊》RPG 卡草案

这是一份依据“毛茸异世界观背景设定构思”整理出的可运行草案，尚未写入 `public/data/worlds.json` 或 `public/data/lorebooks.json`。卡片和世界书必须作为同一内容包导入，`world.lorebookIds` 已指向 `lore-maoruyi-core`。

## 已转成结构化内容

- 世界卡稳定层：世界起源、三重力量、叙事边界、封印边境开局。
- 派系层：终末之舌、无垢之环、金座、逆光之瞳，保留内部矛盾和初始影响力。
- NPC 层：四位主教的公开资料、目标、恐惧、活动位置。
- 玩家层：自定义种族/职业/背景、体魄/洞察/意志/共情、战斗/奥术/生存/调查/交涉。
- 代价层：HP、MP、理智、星辉负荷、深渊侵蚀。
- 回合层：固定四选项、封印裂隙冲突、阵营交涉、封印脉冲和无星之夜事件。

## 明确标记为暂定

1. 大陆地图、国家名称、各地区物种分布。
2. 世界意志的具体人格、目标和可交互方式。
3. 星穹的代行者、组织形式和可见边界。
4. 主线章节、四派系最终结局、世界树自由的具体条件。
5. 玩家是否默认拥有恋爱主线、是否允许多名队伍成员。

## 这次试做暴露的产品缺陷

### P0：世界卡内容容量与作用域不够清晰

一张卡同时承载世界公理、国家地图、派系、NPC、事件和恋爱内容时，Prompt 预算会迅速膨胀。当前虽然有世界上下文预算，但缺少“章节/地区/主线阶段”一级的内容作用域；四个派系的长设定不能每回合都注入。

### P0：Typed Patch 还不能完整表达世界变化

本卡需要“裂隙阶段、派系影响力、NPC 关系、理智阈值、星辉/深渊代价、世界事件阶段”同时变化。现有 patch 主要覆盖玩家数值、背包、地点、效果和目标状态；成长候选、NPC 关系、派系资源、世界事件和冲突动作仍依赖独立流程或旧兼容路径。

### P1：NPC 和派系的认知边界仍偏粗

卡里有公开事实、秘密、恐惧和目标，但当前回合作用域主要按地点、任务、冲突和记忆筛选。需要“谁知道什么、何时知道、谁故意隐瞒”的事实记录，否则涅柯尔的低语、薇瑟拉的同化和艾琉西斯的研究很容易提前泄露。

### P1：理智 / 高维力量缺少专用规则

当前可以把 SAN、星辉负荷和深渊侵蚀声明成资源，但还没有阈值事件、阶段化状态、不可逆后果和恢复规则的统一服务端契约。仅靠 Prompt 会导致同一数值在不同回合被解释成不同结果。

### P1：地图层与世界观地理层脱节

地图算法能生成底图，但这份设定需要国家、封印节点、势力范围和章节路线。现在地图区域更多是视觉区域，尚不能保证“沉降遗迹属于哪一派、星穹观测塔如何连接边境、世界树根脉如何作为终局节点”与剧情事实同步。

### P2：恋爱 / 日常与冒险仍只有提示词级约束

世界观目标是日常恋爱与冒险并行，但当前只有软规则，没有可保存的关系阶段、好感变化来源、日常事件队列、角色边界和恋爱线触发条件。AI 可能在战斗模式中吞掉日常内容，或无依据地推进亲密关系。

### P2：源文档版本和卡片版本还没有绑定

本次来源明确写着“暂定非最终版”。当前草案只在 `source.rawAssetRef` 和 notes 里记录来源，没有源文档哈希、段落映射和“设定变更影响哪些字段”的迁移报告；后续继续改世界观时，容易把旧存档和新版卡混在一起。

## 建议的下一步

先不要把这张卡直接发布为正式世界。下一步最值得做的是增加“内容作用域 + 事件/关系/理智专用 Patch”两项，再用这张卡做隔离回归：两个存档分别走不同派系路线，确认地图、NPC 认知、理智和关系不会串档。
