# 《雾港灯塔：红潮来信》玩法示例卡

这张卡不是单纯的世界观展示，而是用来演示 Tavern RPG 的可玩循环：玩家做选择，世界保存事实，AI 根据事实推进下一轮。

## 可玩的地方

1. **调查**：在档案室、码头和灯塔之间找物证；已确认的事实会进入线索板，而不是只停留在聊天文本里。
2. **探索**：雾林旧路有隐藏捷径、巡逻和迷路代价；玩家可以绕过港口封锁直接走野路。
3. **交涉**：议会、守望者、打捞行各自有目标。帮助一方会改变另一方的态度，不存在单一“正确势力”。
4. **战斗**：礁滩伏击支持客户端 `1d20` 判定。成功、部分成功和失败会分别带来击退、消耗或资源损失。
5. **资源**：生命、专注、潮贝、口粮和灯油都能影响路线；失败不会强制结束，而是把代价写入存档。
6. **动态事件**：潮汐时钟推进后会触发红潮、第十三声钟和港口封锁，世界不会永远停在玩家原地等待。
7. **成长**：确认关键事实或建立势力关系后，可以申请调查技能和身份成长；成长候选由世界卡定义，不写死在前端。
8. **多结局**：玩家可以主动结束，也可以让灯塔沉默或公开开放。初始目标只是“决定先查哪条线”，不是强制主线。
9. **物品动作**：左侧“使用物品”面板可以消耗一份野外口粮；数量归零后动作会自动变为不可用，服务端拒绝重复提交。
10. **技能动作**：左侧“使用技能”面板会把动作交给 Agent；只有完成 `求生` 修正的 `1d20` 判定并成功后，证据变量才会增加。

## 一轮怎么玩

```text
选择地点/行动
  → 普通行动直接推进
  → 需要判定时，Agent 请求客户端骰子
  → 服务端校验骰子与状态补丁
  → AI 描写成功 / 部分成功 / 失败的具体后果
  → 线索、目标、时间、势力和运行时变量写入当前存档
  → 生成下一轮可选行动（仍可自由输入）
```

## 快速测试路线

1. 导入 [demo-gameplay-fog-harbor.tavern-world.json](./demo-gameplay-fog-harbor.tavern-world.json)。
2. 创建存档，角色预设建议先选“码头调查员”，规则选“标准”，首个抓手选“先查港口档案”。
3. 在档案室询问米拉，要求查看“缺失的第十三声记录”。观察线索板是否增加事实、目标是否推进。
4. 再开一个存档，选择“雾林信使”，首个抓手选“先走雾林旧路”。测试雾林判定和失败后的回入口效果。
5. 选择“打捞护卫”走码头，主动触发礁滩伏击。确认骰子动画出现、骰面来自客户端，并且叙事体现结果。
6. 连续推进至少 3 回合，观察 `潮汐时钟`、`第十三声钟` 和港口警戒变化。
7. 在运行时面板测试“记录已确认线索”“提高港口警戒”“登记一项承诺”，刷新后确认只影响当前存档。
8. 在左侧“随身物品/使用物品”面板连续点击“食用野外口粮”，确认数量从 2 变为 1，再次提交时看到不可用提示且存档没有半截变化。
9. 在左侧“使用技能”面板点击“解读潮汐信号”，观察 Agent 先调用判定再提交；失败时 `已确认证据` 不变，成功时增加 1。

## 设计边界

- 使用原生 `world-desk` UI，没有 HTML/JS 扩展，不依赖自定义前端。
- 角色创建、属性、技能、特质、资源、地点、势力、冲突、记忆和运行时变量全部由卡内 JSON 声明。
- 静态设定属于世界卡；时间、线索、承诺、关系和冲突结果属于独立存档，不会串到其他存档。
- Agent 只负责编排工具和叙事；骰子由客户端产生，状态由服务端校验和提交。
