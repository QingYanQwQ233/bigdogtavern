# 灰烬边境：龙火余烬

一张用于测试 RPG 核心闭环的西幻世界卡：边境城、骑士团、商会、月井女巫与逐渐苏醒的古龙契约。

## 这张卡可以测什么

- 开局配置：难度、第一条线索和是否允许 AI 创建新实体；
- 自由行动与 3～4 个卡内选项并存；
- `eat-ration`：消耗一份旅行口粮；
- `drink-mana-vial`：消耗法力药剂并恢复法力；
- `inspect-ember`：使用洞察进行 1d20 判定，成功后确认龙火线索；
- `speak-seraphine`：使用交涉进行 1d20 判定，成功后提高骑士团信任；
- `raise-alert` / `rest-at-inn`：不需要判定的日常 runtime action；
- 关系、线索、警戒、日期和背包状态在回合后持久化。

## 建议测试顺序

1. 导入世界包，创建存档并完成开局配置。
2. 点击“使用口粮”，确认背包数量从 2 变为 1。
3. 再次使用口粮，确认数量变为 0 后动作不可用。
4. 调查龙火碎片，观察 `rules.check → dice.roll → runtime.action.execute` 的工具顺序。
5. 故意输入不存在的物品或动作，确认服务端拒绝，不产生部分状态变化。
6. 刷新页面、重新打开存档，确认线索、信任和物品数量保持不变。
7. 使用自由输入无视当前选项，确认 AI 仍然保留玩家主权。

动态状态属于当前存档，不会写回世界卡本体，也不会与其他存档串联。
