# 潮汐试验场：快捷测试

示例世界卡 ID：`world-test-lab`，标题：`潮汐试验场`。

## 自动自检

在项目根目录运行：

```powershell
node scripts/check_world_test_lab.js
```

脚本会用临时数据目录启动服务，创建存档只作为前置，然后验证：

- Agent `execute → narrate` 两阶段，以及 `state.patch`、`dice.roll`、`rules.check`、`entity.create`、`memory.record` 工具回执；
- 目标、线索、任务的状态推进；
- 战斗、社交、潜行三类冲突和客户端骰子；
- 时间事件、地点事件、势力行动；
- 存档级 NPC 创建、隐藏记忆与记忆诊断；
- 失败结算、成长候选/应用、世界线总结和结局确认。

结束后自动删除临时数据。

若要同时跑现有 Agent / 协议 / 回归检查：

```powershell
node scripts/check_world_test_lab.js
node scripts/check_rpg_agent.js
node scripts/check_rpg_protocol.js
node scripts/check_rpg_patch.js
node scripts/check_rpg_regression.js
```

## 手动冒烟路径

1. `node server.js`，打开 `http://localhost:3000`。
2. 进入 RPG 模式，选择「潮汐试验场」，新建存档；确认此时是“开局规划”而不是直接进入聊天。
3. 角色创建选择「均衡测绘员」，再改一个自定义字段；确认属性点预算为 18，特质可选，`旧伤` 与 `坚韧体魄` 互斥。
4. 在世界规则中切换难度、Sandbox 强度、战斗开关和“允许 AI 创建新实体”；确认只出现世界卡声明的字段。
5. 在开场规划中选择白潮港、米拉，填写时间/事件/前置事实，并分别查看世界真实、角色已知、玩家可见、隐藏和传闻区域。
6. 确认开场后检查四个选项；让 Agent 执行一次“记录任务并前往雾林”，确认任务状态、工具回执、隐藏记忆和存档级 NPC。
7. 回到白潮港触发红潮事件和议会行动；再分别触发战斗“正面反击”、社交“陈述证据”、潜行“追踪脚印”，确认同一客户端骰子包生成三类回执。
8. 将生命降为 0，确认进入“负伤”而非客户端伪造失败；提交 `survey-ruins` 成长候选并接受，确认技能与经验变化。
9. 打开记忆诊断、重建世界线总结，最后执行结局确认；结束后的普通回合应被拒绝。

## 快速异常测试

- 开启“允许 AI 创建新实体”后，让 AI 提议一个新 NPC，确认生成实体使用 `save:<saveId>:npc:<序号>`，不会污染世界卡。
- 在终端检查输入/输出：确认隐藏事实没有进入玩家可见叙事，且模型不能自行伪造骰子结果。
- 复制一个存档后确认副本自动进入对应状态（待开局副本直接打开开局配置，已开始副本进入工作区）；再修改角色属性，确认两个存档的角色、NPC 关系、势力资源和地图数据互不串联。
